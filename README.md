# 🍽️ World-Class White-Label Restaurant Web Platform

A feature-rich, high-performance web platform built for high-end restaurants and sales presentations. Includes **Interactive 360° Table Reservation Visualizer**, **Digital Food & Beverage Menu**, **Omni-Channel Online Ordering (Takeout / Delivery / Dine-In QR)**, **Integrated Guest CRM**, **Bilingual Engine (English & Persian)**, and a **Live White-Label Customizer Tool**.

---

## 🌟 Key Features

1. **360° Interactive Table Reservation Engine**
   - Visual Floorplan map covering Main Dining Lounge, VIP Glass Pavilion, and Outdoor Terrace.
   - Interactive 360-degree virtual perspective simulator from guest table seats.
   - 4-step booking wizard with instant printable QR ticket confirmation.

2. **Digital Menu & Smart Ordering**
   - Multi-category filter with instant search and dietary badges (Vegan, Halal, Gluten-Free).
   - Dish details with calorie counter, preparation time, and sommelier drink pairings.
   - 3 Order Modes: Pickup, Delivery, and Dine-In QR table order.

3. **Integrated CRM & Customer Intelligence**
   - Guest profiles with VIP tiers, order history, allergy alerts, and waiter notes.
   - Targeted campaign SMS sender demo.

4. **Live White-Label Presenter Panel**
   - Change restaurant names, logos, slogans, and branding live in front of clients.
   - Dual Theme Color Modes:
     - 🌙 **Dark Theme**: Black, Yellow/Gold, Dark Gray.
     - ☀️ **Light Theme**: White, Deep Royal Blue, Crimson/Burgundy.

5. **Bilingual Engine (EN & FA)**
   - English default (LTR) with 1-click transition to Persian (RTL).
